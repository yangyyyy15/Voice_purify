# Voice_purify 项目开发规程

> 目标：对已授权视频做说话人分离，输出「谁、在什么时间、说了什么」，并提供 Web UI 人工核验和调整区间。批量裁剪导出放在后续阶段。

## 0. 需求与约束

| 编号 | 需求 | 落地方式 |
|---|---|---|
| R1 | 识别尽量准确 | 多模型流水线 + 自建评测集（DER/CER 指标）驱动调参 |
| R2 | 简便的人工核验 UI | 本地 Web 应用：视频/波形同步播放，区间拖拽、改说话人、改文字 |
| R3 | 过滤非人声（噪音、铃声、音乐） | 人声分离 + VAD + 音频事件分类，三层过滤 |
| R4 | 多人同时说话：放弃识别，但要标出 | 重叠语音检测，标记为 `overlap` 段，不做转写 |

运行环境：
- 运行机：台式机，NVIDIA 24GB 显存、48GB 内存，Windows。
- 当前云桌面（Intel 核显）只用于写代码，不跑模型。
- 语言：主要是普通话。
- 说话人：第一阶段自动聚类，再由人工命名；后期积累样本后加声纹库自动认人。

## 1. 技术路线总览

```
视频
 └─(1) ffmpeg 抽音轨 ──> 原始音频 48kHz（导出用） + 16kHz 单声道（分析用）
      └─(2) 人声分离 Demucs htdemucs ──> vocals 轨（去背景音乐/大部分环境声）
           └─(3) VAD 语音活动检测 ──> 候选语音区间
                ├─(4) 音频事件分类 PANNs/BEATs ──> 剔除铃声、笑声、掌声等非语音
                ├─(5) 说话人分离 pyannote ──> 说话人标签 + 重叠区间
                └─(6) 中文 ASR FunASR Paraformer ──> 文字 + 字级时间戳
                     └─(7) 合并对齐：每个字按时间归属到说话人，切成句级片段
                          └─(8) 输出 project.json ──> Web UI 核验 ──> 修正后保存
```

设计原则：
- 每一步产物都落盘（缓存），可单独重跑某一步，方便调参和对比。
- 分析和导出分开：分析用降噪后的 16kHz 音频，导出用原始音频的同一时间区间，避免分离算法引入的音质损伤。
- 模型可替换：每个环节定义统一接口，便于 A/B 对比（例如 Paraformer 和 Whisper 对比）。

## 2. 技术选型（为什么选这些）

| 环节 | 选型 | 理由 | 备选 |
|---|---|---|---|
| 抽音/格式 | ffmpeg | 行业标准，什么容器都能拆 | — |
| 人声分离 | Demucs (htdemucs) | 开源最强人声分离之一，分出 vocals 轨能显著去掉音乐/环境声，直接服务 R3 | MDX-Net、UVR5 |
| VAD | Silero VAD | 轻量准确，门槛低；pyannote 内部也有 VAD 可交叉验证 | WebRTC VAD（更糙） |
| 音频事件分类 | PANNs (Cnn14) | AudioSet 预训练，能识别铃声/音乐/笑声等，用于 R3 二次过滤 | YAMNet、BEATs |
| 说话人分离 | pyannote 3.1 (speaker-diarization-3.1) | 当前开源 diarization SOTA，自带重叠检测，直接服务 R4 | NeMo diarization |
| 中文 ASR | FunASR Paraformer-large + 时间戳 | 中文识别精度高于 Whisper，自带标点和字级时间戳 | Whisper large-v3（中英混） |
| 对齐 | 自研时间轴合并 | 把 ASR 字级时间戳按说话人区间归属 | WhisperX（英文更成熟） |

> 注：pyannote 需要在 Hugging Face 接受模型使用条款并申请 token。FunASR 从 ModelScope 下载，国内网络更友好。两条关键依赖在环境搭建阶段先验证通。

关于语言选择：你视频主要是中文，所以主 ASR 用 **FunASR Paraformer**（中文强于 Whisper）。保留 Whisper large-v3 作为可切换后端，用于偶发中英混说的情况。

## 5. 开发阶段与里程碑

### 阶段 0：环境搭建（1 步，必须最先通过验收）
1. 台式机装 Python 3.10/3.11（不要 3.13，CUDA 轮子不全）、ffmpeg、CUDA 对应的 PyTorch。
2. 验收脚本 `backend/check_env.py`：打印 GPU 是否可用、显存大小、各模型能否加载。
3. 跑通 pyannote token、FunASR/ModelScope 下载、Demucs 权重下载。
- **验收标准**：`check_env.py` 全绿，能在 GPU 上加载四个模型不报错。

### 阶段 1：离线流水线（核心，优先交付 R1/R3/R4）
按 step1→step7 顺序实现，每步可独立运行、产物落盘。
- 里程碑 M1：拿一个 10 分钟测试视频，跑完整条流水线，生成 project.json。
- **验收标准**：输出文件里时间段、说话人标签、文字三者齐全；铃声/音乐段被标 `non_speech`；多人同说段被标 `overlap`。

### 阶段 2：核验 UI（落地 R2，最低要求的终点）
- 视频播放器 + 波形图（wavesurfer.js）时间轴同步。
- 左侧说话人列表（改名、改颜色）；主区时间线片段，可拖拽边界、拆分/合并、改说话人、改文字。
- 点片段跳播、循环试听；`overlap`/`low_conf` 片段高亮。
- 保存写回 project.json。
- **验收标准**：能打开 M1 的结果，完成一次完整人工核验并保存。

### 阶段 3：评测与调参（支撑 R1「尽量准确」）
- 人工标注 2~3 段作为 ground truth，脚本算 DER（分离错误率）、CER（字错误率）。
- 用指标对比模型/参数（Paraformer vs Whisper、VAD 阈值、Demucs 开关）。
- **验收标准**：有可复现的评测报告，指标达到你能接受的线。

### 阶段 4：批量裁剪导出（后续增强）
- 按说话人/按片段批量导出音频（从 48kHz 原轨切，保音质）。
- 导出 SRT/CSV/分角色音频包。

### 阶段 5（可选）：声纹库自动认人
- 积累命名样本后，用说话人 embedding 建注册库，新视频自动匹配人名（你之前说的「方案2」）。

### Step 1: 音频提取（step1_extract.py）

**目的**：从视频抽音轨，生成两个版本：
- `full_48k.wav`：原始采样率，保留音质，用于最终导出。
- `analysis_16k.wav`：16kHz 单声道，给后续分析用（降低计算量）。

```python
import ffmpeg
import os

def extract_audio(video_path: str, cache_dir: str):
    """
    Args:
        video_path: 输入视频路径
        cache_dir: 输出目录，如 data/cache/abc123/
    Returns:
        (full_path, analysis_path)
    """
    os.makedirs(cache_dir, exist_ok=True)
    
    full_path = os.path.join(cache_dir, "full_48k.wav")
    analysis_path = os.path.join(cache_dir, "analysis_16k.wav")
    
    # 提取原始音轨（保留采样率）
    ffmpeg.input(video_path).output(
        full_path, 
        acodec='pcm_s16le', 
        ac=1  # 转单声道，多声道会让说话人分离混乱
    ).overwrite_output().run(quiet=True)
    
    # 降采样到 16kHz（模型标准输入）
    ffmpeg.input(full_path).output(
        analysis_path,
        ar=16000
    ).overwrite_output().run(quiet=True)
    
    # 获取时长
    probe = ffmpeg.probe(video_path)
    duration = float(probe['format']['duration'])
    
    return full_path, analysis_path, duration

# 用法：
# full, analysis, dur = extract_audio("data/input/test.mp4", "data/cache/test_001")
```

**注意点**：
- 必须转单声道（`ac=1`），否则后续 diarization 会把左右声道误判为两个说话人。
- 如果原视频已经是单声道或立体声混音干净，可保留；但保险起见统一单声道。

### Step 2: 人声分离（step2_separate.py）

**目的**：用 Demucs 分离出纯人声轨，去掉音乐、大部分环境声，服务 R3。

```python
import subprocess
import os

def separate_vocals(audio_path: str, cache_dir: str):
    """
    调用 Demucs htdemucs 模型分离，输出 vocals.wav
    
    Args:
        audio_path: data/cache/xxx/full_48k.wav
            注意：要用高采样率原轨。Demucs 的训练数据是 44.1kHz，喂 16kHz 会降低分离质量。
            分离后再把 vocals.wav 降采样到 16kHz 单声道，作为 step3~6 的输入。
        cache_dir: 输出根目录
    Returns:
        vocals_path: 分离出的人声文件路径
    """
    # Demucs 会在 cache_dir/htdemucs/<stem> 下输出各轨
    cmd = [
        "demucs",
        "--two-stems=vocals",  # 只分人声和伴奏，更快
        "-n", "htdemucs",      # 模型版本
        "-o", cache_dir,       # 输出目录
        audio_path
    ]
    
    subprocess.run(cmd, check=True, capture_output=True)
    
    # 输出路径规则：cache_dir/htdemucs/<文件名>/vocals.wav
    stem_name = os.path.splitext(os.path.basename(audio_path))[0]
    vocals_path = os.path.join(cache_dir, "htdemucs", stem_name, "vocals.wav")
    
    if not os.path.exists(vocals_path):
        raise FileNotFoundError(f"Demucs 输出未找到: {vocals_path}")
    
    return vocals_path

# 用法：
# vocals = separate_vocals("data/cache/test_001/analysis_16k.wav", "data/cache/test_001")
```

**性能**：
- 24GB 显存，处理 1 小时音频约需 3-5 分钟。
- 首次运行会下载模型（~300MB）。
- 如果视频本身没有背景音乐/杂音，这步可跳过或做 A/B 对比（评测时关闭此步看效果差异）。

### Step 3: 语音活动检测 VAD（step3_vad.py）

**目的**：找出所有「可能有人说话」的时间段，过滤长静音，减少后续计算量。

```python
import torch
from silero_vad import load_silero_vad, get_speech_timestamps, read_audio

def run_vad(audio_path: str, threshold=0.5):
    """
    Args:
        audio_path: 人声轨路径（vocals.wav）
        threshold: 置信度阈值，0.3-0.7，越低越敏感
    Returns:
        List[dict]: [{'start': 秒, 'end': 秒}, ...]
    """
    model = load_silero_vad()
    wav = read_audio(audio_path, sampling_rate=16000)
    
    # 返回时间戳列表，单位是采样点
    speech_timestamps = get_speech_timestamps(
        wav, 
        model, 
        threshold=threshold,
        sampling_rate=16000,
        min_speech_duration_ms=250,  # 至少 250ms 算一段
        min_silence_duration_ms=300  # 静音 300ms 以上才切断
    )
    
    # 转成秒
    segments = [
        {'start': ts['start'] / 16000, 'end': ts['end'] / 16000}
        for ts in speech_timestamps
    ]
    
    return segments

# 用法：
# vad_segs = run_vad("data/cache/test_001/vocals_16k.wav")
# print(f"检测到 {len(vad_segs)} 个语音段")
```

**参数调优**：
- `threshold=0.5`：标准敏感度，漏检少但可能有些咳嗽/呼吸声混入。
- `threshold=0.3`：更激进，适合轻声说话或信号差的场景。
- 后面评测时可以对比这个参数对最终 DER 的影响。

### Step 4: 音频事件分类（step4_events.py）

**目的**：二次过滤 VAD 输出，剔除铃声、笑声、音乐残留等非语音事件，落地 R3。

```python
import torch
import numpy as np
import librosa
from panns_inference import AudioTagging

def classify_audio_events(audio_path: str, segments: list):
    """
    Args:
        audio_path: 人声轨
        segments: VAD 输出的候选区间列表
    Returns:
        filtered_segments: 只保留纯语音的区间
        rejected_segments: 被剔除的区间（标记 type='non_speech'）
    """
    # 加载 PANNs 模型（Cnn14，AudioSet 527 类别预训练）
    at = AudioTagging(checkpoint_path=None, device='cuda')  # 自动下载
    
    audio, sr = librosa.load(audio_path, sr=32000)  # PANNs 要求 32kHz
    
    speech_labels = {'Speech', 'Male speech, man speaking', 'Female speech, woman speaking',
                     'Child speech, kid speaking', 'Conversation', 'Narration, monologue'}
    noise_labels = {'Music', 'Ringtone', 'Telephone', 'Laughter', 'Applause', 'Siren'}
    
    filtered = []
    rejected = []
    
    for seg in segments:
        start_sample = int(seg['start'] * sr)
        end_sample = int(seg['end'] * sr)
        clip = audio[start_sample:end_sample]
        
        if len(clip) < sr * 0.5:  # 太短（<0.5秒）跳过分类，默认保留
            filtered.append(seg)
            continue
        
        # 推理
        (clipwise_output, _) = at.inference(clip[None, :])  # shape (1, 527)
        
        # 找最高置信度的标签
        top_idx = np.argmax(clipwise_output[0])
        top_label = at.labels[top_idx]
        top_conf = clipwise_output[0][top_idx]
        
        if top_label in noise_labels and top_conf > 0.3:
            rejected.append({**seg, 'type': 'non_speech', 'reason': top_label})
        else:
            filtered.append(seg)
    
    return filtered, rejected

# 用法：
# speech_segs, noise_segs = classify_audio_events(vocals_path, vad_segs)
# print(f"保留 {len(speech_segs)} 段，剔除 {len(noise_segs)} 段噪音")
```

**阈值说明**：
- `top_conf > 0.3`：当铃声/音乐置信度大于 0.3 时才剔除。太低会误杀真实语音。
- 可在评测时统计「被误判为噪音的真语音」占比，调整这个阈值。
- 如果视频干净（无铃声音乐），这步可选做或阈值调高到 0.5。

### Step 5: 说话人分离 + 重叠检测（step5_diarize.py）

**目的**：给每个语音段打上说话人标签（SPEAKER_00, SPEAKER_01...），并标出多人同时说话的重叠区间（R4）。

```python
from pyannote.audio import Pipeline
import torch

def diarize_speakers(audio_path: str, hf_token: str):
    """
    Args:
        audio_path: 人声轨路径
        hf_token: Hugging Face token（环境变量 HF_TOKEN）
    Returns:
        diarization: pyannote Annotation 对象
        overlap_segments: 重叠区间列表 [{'start': x, 'end': y}, ...]
    """
    pipeline = Pipeline.from_pretrained(
        "pyannote/speaker-diarization-3.1",
        use_auth_token=hf_token
    )
    pipeline.to(torch.device("cuda"))
    
    # 运行分离
    diarization = pipeline(audio_path)
    
    # 提取重叠区间（pyannote 3.1 内置）
    from pyannote.core import Timeline
    overlap_timeline = diarization.get_overlap()  # Timeline 对象
    
    overlap_segments = [
        {'start': segment.start, 'end': segment.end}
        for segment in overlap_timeline
    ]
    
    return diarization, overlap_segments

def parse_diarization(diarization):
    """
    把 pyannote Annotation 转成易用的列表
    Returns:
        [{'start': 秒, 'end': 秒, 'speaker': 'SPEAKER_00'}, ...]
    """
    segments = []
    for turn, _, speaker in diarization.itertracks(yield_label=True):
        segments.append({
            'start': turn.start,
            'end': turn.end,
            'speaker': speaker
        })
    return segments
```

### Step 6: 中文语音识别 ASR（step6_asr.py）

**目的**：把语音转成文字，并获取字级时间戳（用于对齐）。

```python
from funasr import AutoModel

def transcribe_chinese(audio_path: str):
    """
    Args:
        audio_path: 人声轨路径
    Returns:
        transcription: {
            'text': '完整文本',
            'words': [{'word': '今天', 'start': 1.2, 'end': 1.5}, ...]
        }
    """
    # 加载 FunASR Paraformer 模型（中文 + 标点 + 时间戳）
    model = AutoModel(
        model="paraformer-zh",  # ModelScope 别名
        model_revision="v2.0.4",
        vad_model="fsmn-vad",
        punc_model="ct-punc",
        # device="cuda"  # 自动检测
    )
    
    # 推理
    res = model.generate(
        input=audio_path,
        batch_size_s=300,  # 每批处理 300 秒
        hotword='',        # 热词，可加行业术语提升准确率
        timestamp=True     # 返回字级时间戳
    )
    
    # 解析输出（FunASR 格式）
    result = res[0]
    text = result['text']
    
    # 字级时间戳：result['timestamp'] 是 [[start_ms, end_ms], ...]，
    # 每项对应一个字（不含标点），文字本身要从 text 里去掉标点后逐字对应。
    # 注意：不同 FunASR 版本输出字段可能不同，首次运行先 print(result) 确认结构。
    import re
    chars = [c for c in re.sub(r'[，。？！、,.?!\s]', '', text)]
    words = []
    for ch, (s_ms, e_ms) in zip(chars, result.get('timestamp', [])):
        words.append({'word': ch, 'start': s_ms / 1000.0, 'end': e_ms / 1000.0})
    # 如有英文单词，chars 按字符拆会和时间戳数量对不上，此时需按 FunASR 的分词规则处理
    
    return {'text': text, 'words': words}
```

### Step 7: 时间轴对齐合并（step7_merge.py）

**目的**：把 ASR 的字级时间戳按说话人区间归属，切成句级片段，合并所有信息到 project.json。

这是最复杂的一步，需要处理三种输入：
1. 说话人区间（step5 输出）
2. ASR 字级时间戳（step6 输出）
3. 重叠区间（step5 输出）

```python
import json
from typing import List, Dict
from uuid import uuid4

def merge_timeline(
    speaker_segments: List[Dict],   # [{'start', 'end', 'speaker'}, ...]
    words: List[Dict],               # [{'word', 'start', 'end'}, ...]
    overlap_segments: List[Dict],    # [{'start', 'end'}, ...]
    non_speech_segments: List[Dict]  # step4 剔除的噪音段
) -> List[Dict]:
    """
    Returns:
        合并后的最终片段列表，每个元素：
        {
            'id': 'seg_xxxx',
            'start': 1.2,
            'end': 5.8,
            'speaker': 'SPEAKER_00',
            'text': '今天我们讨论一下。',
            'words': [...],
            'type': 'speech' | 'overlap' | 'non_speech',
            'confidence': 0.9,
            'reviewed': False,
            'flags': []
        }
    """
    merged = []
    
    # 1. 标记重叠区间
    overlap_set = set()
    for ov in overlap_segments:
        # 记录时间范围（简化：用 10ms 为单位的整数索引）
        for t in range(int(ov['start'] * 100), int(ov['end'] * 100)):
            overlap_set.add(t)
    
    def is_overlap(start, end):
        mid = int((start + end) / 2 * 100)
        return mid in overlap_set
    
    # 2. 遍历说话人区间，给每段分配文字
    for seg in speaker_segments:
        seg_start, seg_end = seg['start'], seg['end']
        speaker = seg['speaker']
        
        # 检查是否重叠
        if is_overlap(seg_start, seg_end):
            merged.append({
                'id': f"seg_{uuid4().hex[:8]}",
                'start': seg_start,
                'end': seg_end,
                'speaker': speaker,
                'text': '[多人同时说话]',
                'words': [],
                'type': 'overlap',
                'confidence': 0.0,
                'reviewed': False,
                'flags': ['overlap']
            })
            continue
        
        # 找这个时间段内的所有字：按字的中点归属，避免边界字因几十毫秒偏差被丢掉
        seg_words = [
            w for w in words
            if seg_start <= (w['start'] + w['end']) / 2 < seg_end
        ]
        
        # 拼成句子
        text = ''.join([w['word'] for w in seg_words])
        
        # 置信度（简化：按时长占比估算）
        if seg_end - seg_start > 0:
            word_coverage = sum(w['end'] - w['start'] for w in seg_words) / (seg_end - seg_start)
            confidence = min(word_coverage, 1.0)
        else:
            confidence = 0.5
        
        # 标记质量问题
        flags = []
        if confidence < 0.6:
            flags.append('low_conf')
        if seg_end - seg_start < 0.5:
            flags.append('short')
        
        merged.append({
            'id': f"seg_{uuid4().hex[:8]}",
            'start': seg_start,
            'end': seg_end,
            'speaker': speaker,
            'text': text,
            'words': seg_words,
            'type': 'speech',
            'confidence': round(confidence, 2),
            'reviewed': False,
            'flags': flags
        })
    
    # 3. 加入被剔除的非语音段
    for ns in non_speech_segments:
        merged.append({
            'id': f"seg_{uuid4().hex[:8]}",
            'start': ns['start'],
            'end': ns['end'],
            'speaker': None,
            'text': f"[{ns.get('reason', '非人声')}]",
            'words': [],
            'type': 'non_speech',
            'confidence': 0.0,
            'reviewed': False,
            'flags': ['non_speech']
        })
    
    # 4. 按时间排序
    merged.sort(key=lambda x: x['start'])
    
    return merged

# 用法：
# final_segments = merge_timeline(speaker_segs, transcript['words'], overlaps, noise_segs)
```

**复杂度说明**：
- 时间对齐需要容错：ASR 时间戳和 diarization 边界可能有几百毫秒偏差。
- 上面代码是简化版（按中点判断重叠、直接截取字），实际可加「边界模糊匹配」「字向说话人段投票」等策略。
- 评测时统计「边界对齐误差」，如果平均超过 0.5 秒，说明需要优化对齐算法。

把上面 7 步串起来，做缓存管理和进度追踪。

```python
import os
import json
import ffmpeg
from step1_extract import extract_audio
from step2_separate import separate_vocals
from step3_vad import run_vad
from step4_events import classify_audio_events
from step5_diarize import diarize_speakers, parse_diarization
from step6_asr import transcribe_chinese
from step7_merge import merge_timeline

def run_pipeline(video_path: str, project_name: str, force_rerun: dict = None):
    """
    Args:
        video_path: 输入视频路径
        project_name: 项目唯一标识
        force_rerun: {'step2': True, 'step5': True} 强制重跑某些步骤
    Returns:
        project_json_path: 输出的 project.json 路径
    """
    force_rerun = force_rerun or {}
    cache_dir = f"data/cache/{project_name}"
    os.makedirs(cache_dir, exist_ok=True)
    
    print("=== Step 1: 音频提取 ===")
    step1_cache = os.path.join(cache_dir, "full_48k.wav")
    if not os.path.exists(step1_cache) or force_rerun.get('step1'):
        full_audio, analysis_audio, duration = extract_audio(video_path, cache_dir)
    else:
        print("  使用缓存")
        analysis_audio = os.path.join(cache_dir, "analysis_16k.wav")
        import subprocess
        probe = subprocess.run(
            ['ffprobe', '-v', 'error', '-show_entries', 'format=duration', 
             '-of', 'default=noprint_wrappers=1:nokey=1', step1_cache],
            capture_output=True, text=True
        )
        duration = float(probe.stdout.strip())
    
    print("=== Step 2: 人声分离 ===")
    # Demucs 吃 48k 原轨，输出的 vocals 再降到 16k 单声道给后续分析
    step2_cache = os.path.join(cache_dir, "vocals_16k.wav")
    if not os.path.exists(step2_cache) or force_rerun.get('step2'):
        vocals_hq = separate_vocals(os.path.join(cache_dir, "full_48k.wav"), cache_dir)
        ffmpeg.input(vocals_hq).output(step2_cache, ar=16000, ac=1).overwrite_output().run(quiet=True)
    else:
        print("  使用缓存")
    vocals_path = step2_cache
    
    print("=== Step 3: VAD ===")
    step3_cache = os.path.join(cache_dir, "vad_segments.json")
    if not os.path.exists(step3_cache) or force_rerun.get('step3'):
        vad_segments = run_vad(vocals_path)
        with open(step3_cache, 'w') as f:
            json.dump(vad_segments, f)
    else:
        print("  使用缓存")
        with open(step3_cache) as f:
            vad_segments = json.load(f)
    
    print("=== Step 4: 音频事件分类 ===")
    step4_cache = os.path.join(cache_dir, "filtered_segments.json")
    if not os.path.exists(step4_cache) or force_rerun.get('step4'):
        speech_segs, noise_segs = classify_audio_events(vocals_path, vad_segments)
        with open(step4_cache, 'w') as f:
            json.dump({'speech': speech_segs, 'noise': noise_segs}, f)
    else:
        print("  使用缓存")
        with open(step4_cache) as f:
            data = json.load(f)
            speech_segs, noise_segs = data['speech'], data['noise']
    
    print("=== Step 5: 说话人分离 ===")
    step5_cache = os.path.join(cache_dir, "diarization.json")
    if not os.path.exists(step5_cache) or force_rerun.get('step5'):
        hf_token = os.getenv("HF_TOKEN")
        diarization, overlaps = diarize_speakers(vocals_path, hf_token)
        speaker_segs = parse_diarization(diarization)
        with open(step5_cache, 'w') as f:
            json.dump({'speakers': speaker_segs, 'overlaps': overlaps}, f)
    else:
        print("  使用缓存")
        with open(step5_cache) as f:
            data = json.load(f)
            speaker_segs, overlaps = data['speakers'], data['overlaps']
    
    print("=== Step 6: ASR ===")
    step6_cache = os.path.join(cache_dir, "transcript.json")
    if not os.path.exists(step6_cache) or force_rerun.get('step6'):
        transcript = transcribe_chinese(vocals_path)
        with open(step6_cache, 'w') as f:
            json.dump(transcript, f, ensure_ascii=False)
    else:
        print("  使用缓存")
        with open(step6_cache) as f:
            transcript = json.load(f)
    
    print("=== Step 7: 合并对齐 ===")
    final_segments = merge_timeline(
        speaker_segs, transcript['words'], overlaps, noise_segs
    )
    
    # 生成 project.json
    speakers_unique = list(set(s['speaker'] for s in speaker_segs))
    speakers = [
        {'id': spk, 'name': '未命名', 'color': f"#{''.join([hex(hash(spk) >> i & 0xFF)[2:].zfill(2) for i in [0,8,16]])}"}
        for spk in speakers_unique
    ]
    
    project = {
        'video_id': project_name,
        'source_video': video_path,
        'audio_analysis': vocals_path,
        'audio_export': step1_cache,
        'duration': duration,
        'speakers': speakers,
        'segments': final_segments
    }
    
    project_json_path = f"data/projects/{project_name}.json"
    os.makedirs("data/projects", exist_ok=True)
    with open(project_json_path, 'w', encoding='utf-8') as f:
        json.dump(project, f, ensure_ascii=False, indent=2)
    
    print(f"\n✓ 完成！项目文件: {project_json_path}")
    print(f"  识别出 {len(speakers)} 个说话人")
    print(f"  生成 {len(final_segments)} 个片段")
    print(f"  重叠片段: {len([s for s in final_segments if s['type'] == 'overlap'])}")
    print(f"  非人声: {len([s for s in final_segments if s['type'] == 'non_speech'])}")
    
    return project_json_path
```

```tsx
import RegionsPlugin from 'wavesurfer.js/dist/plugins/regions';
import { useEffect, useRef } from 'react';

export function WaveformTimeline({ audioUrl, segments, onSegmentClick, onSegmentUpdate }) {
  const containerRef = useRef(null);
  const wavesurferRef = useRef(null);
  
  useEffect(() => {
    // 初始化 wavesurfer
    const ws = WaveSurfer.create({
      container: containerRef.current,
      waveColor: '#ddd',
      progressColor: '#3b82f6',
      height: 128,
      plugins: [RegionsPlugin.create()]
    });
    
    ws.load(audioUrl);
    wavesurferRef.current = ws;
    
    // 渲染片段区域
    const regions = ws.registerPlugin(RegionsPlugin.create());
    segments.forEach(seg => {
      regions.addRegion({
        id: seg.id,
        start: seg.start,
        end: seg.end,
        color: getSpeakerColor(seg.speaker, seg.type),
        drag: true,
        resize: true
      });
    });
    
    // 监听拖拽/调整
    regions.on('region-updated', (region) => {
      onSegmentUpdate(region.id, {
        start: region.start,
        end: region.end
      });
    });
    
    regions.on('region-clicked', (region, e) => {
      ws.setTime(region.start);
      onSegmentClick(region.id);
    });
    
    return () => ws.destroy();
  }, [audioUrl, segments]);
  
  return <div ref={containerRef} className="waveform-container" />;
}
```

```typescript
import { useEffect } from 'react';

export function useAudioSync(videoRef, wavesurferRef) {
  useEffect(() => {
    const video = videoRef.current;
    const ws = wavesurferRef.current;
    if (!video || !ws) return;
    
    // 视频播放时同步波形进度
    const onTimeUpdate = () => {
      ws.setTime(video.currentTime);
    };
    
    // 视频播放/暂停时同步波形
    const onPlay = () => ws.play();
    const onPause = () => ws.pause();
    
    video.addEventListener('timeupdate', onTimeUpdate);
    video.addEventListener('play', onPlay);
    video.addEventListener('pause', onPause);
    
    return () => {
      video.removeEventListener('timeupdate', onTimeUpdate);
      video.removeEventListener('play', onPlay);
      video.removeEventListener('pause', onPause);
    };
  }, [videoRef, wavesurferRef]);
}
```

## 9. 评测体系（阶段 3）

### 9.1 评测指标

| 指标 | 含义 | 计算方式 | 目标值 |
|---|---|---|---|
| DER (Diarization Error Rate) | 说话人分离错误率 | (漏检时长 + 误检时长 + 混淆时长) / 总时长 | < 15% |
| CER (Character Error Rate) | 字错误率 | (替换 + 插入 + 删除) / 总字数 | < 8% |
| VAD Precision/Recall | 语音检测准确率/召回率 | TP/(TP+FP), TP/(TP+FN) | P>90%, R>85% |
| Overlap Detection F1 | 重叠检测 F1 值 | 2PR/(P+R) | > 70% |
| Non-speech Filter Acc | 非人声过滤准确率 | 正确剔除的噪音段 / 总噪音段 | > 85% |

### 9.3 评测脚本（tests/eval/evaluate.py）

```python
import json
from typing import List, Dict

def align_segments(pred: List[Dict], gt: List[Dict], tolerance=0.5):
    """
    按时间对齐预测和标注，tolerance 为边界容差（秒）
    """
    aligned = []
    for p in pred:
        for g in gt:
            # IoU (Intersection over Union)
            overlap_start = max(p['start'], g['start'])
            overlap_end = min(p['end'], g['end'])
            if overlap_end > overlap_start:
                iou = (overlap_end - overlap_start) / (
                    max(p['end'], g['end']) - min(p['start'], g['start'])
                )
                if iou > 0.5:  # 50% 重叠算对应
                    aligned.append({'pred': p, 'gt': g, 'iou': iou})
    return aligned

def compute_der(pred_speakers, gt_speakers, total_duration):
    """
    计算 DER（简化版，精确版需要用 pyannote.metrics）
    """
    # 按 0.1 秒时间片统计
    pred_timeline = [None] * int(total_duration * 10)
    gt_timeline = [None] * int(total_duration * 10)
    
    for seg in pred_speakers:
        for i in range(int(seg['start'] * 10), int(seg['end'] * 10)):
            if i < len(pred_timeline):
                pred_timeline[i] = seg['speaker']
    
    for seg in gt_speakers:
        for i in range(int(seg['start'] * 10), int(seg['end'] * 10)):
            if i < len(gt_timeline):
                gt_timeline[i] = seg['speaker']
    
    # 计算错误
    errors = sum(1 for p, g in zip(pred_timeline, gt_timeline) if p != g)
    der = errors / len(gt_timeline) if gt_timeline else 1.0
    return der

def compute_cer(pred_text, gt_text):
    """
    计算字错误率（用 editdistance 库）
    """
    import editdistance
    dist = editdistance.eval(pred_text, gt_text)
    cer = dist / len(gt_text) if gt_text else 0
    return cer

def evaluate_project(project_path, gt_path):
    with open(project_path, 'r', encoding='utf-8') as f:
        pred = json.load(f)
    with open(gt_path, 'r', encoding='utf-8') as f:
        gt = json.load(f)
    
    # 1. DER
    der = compute_der(pred['segments'], gt['segments'], pred['duration'])
    
    # 2. CER
    pred_text = ''.join(s['text'] for s in pred['segments'] if s['type'] == 'speech')
    gt_text = ''.join(s['text'] for s in gt['segments'])
    cer = compute_cer(pred_text, gt_text)
    
    # 3. Overlap Detection
    pred_overlaps = [s for s in pred['segments'] if s['type'] == 'overlap']
    gt_overlaps = [s for s in gt['segments'] if s.get('type') == 'overlap']
    overlap_aligned = align_segments(pred_overlaps, gt_overlaps)
    overlap_precision = len(overlap_aligned) / len(pred_overlaps) if pred_overlaps else 0
    overlap_recall = len(overlap_aligned) / len(gt_overlaps) if gt_overlaps else 0
    overlap_f1 = 2 * overlap_precision * overlap_recall / (overlap_precision + overlap_recall) \
                 if (overlap_precision + overlap_recall) > 0 else 0
    
    report = {
        'DER': f"{der * 100:.2f}%",
        'CER': f"{cer * 100:.2f}%",
        'Overlap F1': f"{overlap_f1 * 100:.2f}%"
    }
    
    return report
```

## 10. 后续阶段要点

### 阶段 4：批量裁剪导出
- 只导出 `reviewed=true` 且 `type=speech` 的片段，从 `full_48k.wav` 按区间切（ffmpeg `-ss/-to`，或 soundfile 直接按采样点切）。
- 首尾各留 50~100ms 余量，避免切掉字头字尾。
- 输出结构：`export/<视频id>/<说话人名>/<序号>_<开始时间>.wav`，另附 `index.csv`（文件名、时间、文字）和 SRT 字幕。
- 可选：导出时用 Demucs 人声轨代替原轨（更干净但有音质损伤），做成开关。

### 阶段 5：声纹库自动认人
- 用 pyannote 的 embedding 模型（`pyannote/wespeaker-voxceleb-resnet34-LM`）对人工命名过的片段提取声纹向量，每人保存多条，存入 `data/voiceprints/<人名>.npy`。
- 新视频跑完聚类后，算每个 SPEAKER_xx 的平均向量和声纹库的余弦相似度，超过阈值（先设 0.7，再用评测集校准）就自动填人名，否则保持「未命名」。
- 自动认出的人名在 UI 里标「待确认」，人工点确认后再并入声纹库，防止错误样本污染声纹库。

## 11. 风险与应对

| 风险 | 影响 | 应对 |
